# Algorithms

Python implementations of classic algorithms from CSC 440 (Algorithms) at the University of Rhode Island, each with tests, benchmarks, or a written analysis.

| Project | Problem | Technique | Language |
|---|---|---|---|
| Convex Hull | Find the points on the boundary of a point set | Divide and conquer | Python |
| Stable Matching | Pair two groups so no pair would rather switch | Gale-Shapley | Python |
| Huffman Compression | Compress and decompress files without loss | Greedy algorithm, priority queue | Python |
| Seam Carving | Resize an image while keeping its important content | Dynamic programming | Python |
| Pocket Cube Solver | Solve a 2x2x2 Rubik's Cube in the fewest moves | Two-way breadth-first search | Python |

## Running

Each project is self-contained and needs Python 3. Projects with plots need `matplotlib`:

```bash
pip install matplotlib
```
